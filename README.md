# Alexandria Car Clinic — website

One-page scroll site. Static HTML + two CSS files + one vanilla-JS file. No framework,
no scroll library, no build step. The motion engine is adapted from the Loco Exotics
build (`SCROLL-SITE-PLAYBOOK.md` in that repo). Design system: `docs/design/DESIGN.md`.
Client facts: `docs/content/client-brief.md`. Plan: `docs/plan/site-plan.md`.

```
index.html          all markup and copy
css/tokens.css      design tokens (midnight-navy palette)
css/site.css        all styles
js/motion.js        scroll engine, text reveals, services index, form
fonts/              self-hosted Inter (variable)
media/              scroll films + posters (generated by the "Prepare media" workflow)
media/services/     16 service photos (see below)
media/team/         3 team photos
```

## Media films
`media/manifest.txt` lists the Higgsfield clips (name, URL, seconds to trim off the start,
seconds to trim off the end, `interp` to smooth to 48fps). Run **Actions → Prepare media** to download, re-encode
(keyframe every 4 frames, needed for smooth scrubbing) and commit `media/hero.mp4`,
`media/lift.mp4` and their posters. It also writes contact sheets to `media/qa/` to eyeball
the result. Change a trim value or swap a URL, then run it again.

- **Hero (`hero`)**: the M2 driving off. Scrubbed forward as you scroll.
- **Lift (`lift`)**: the AMG. Generated lowering; the page plays it in reverse so it rises.

## Photos (drop files in, no code changes)
Service photos, JPG, ideally 1600×1200 (4:3), named exactly:
`oil-change`, `brakes`, `engine-diagnostics`, `electrical-battery`, `steering-suspension`,
`ac-heating`, `tires-alignment`, `belts-hoses-cooling`, `transmission-service`,
`engine-replacement`, `transmission-replacement`, `differentials`, `collision-repair`,
`bodywork-paint`, `detailing`, `undercoating` → `media/services/<name>.jpg`.

Team photos (4:5 portrait): `media/team/team-1.jpg`, `team-2.jpg`, `team-3.jpg`.

Until a photo exists the page shows a dashed "photo coming soon" frame in its place.
